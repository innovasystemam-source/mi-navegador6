# Tablet Browser

Navegador Android local (WebView) con modos Móvil / Tablet / Escritorio.

1. Abre esta carpeta en Android Studio (Hedgehog o más nuevo).
2. Espera la sincronización de Gradle.
3. Run ▶ en un teléfono o emulador.

El modo cambia el User-Agent y el ancho de viewport:
Móvil = normal, Tablet = 800 px, Escritorio = 1280 px (ver `Mode` en MainActivity.kt).
